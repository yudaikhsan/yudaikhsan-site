## The brief

Three product releases. Three product teams. Three plans that had quietly been written in
parallel, each convinced its launch deserved the loudest moment of the year.

Left alone, the result would have been predictable: three unconnected pushes competing
for the same journalists, the same budget, and the same audience attention — and a
company that looked like it was shouting in three directions at once.

## What I did

- Built **one message architecture** that spanned all three launches, so each release
  proved the same underlying idea instead of inventing its own.
- Mapped the media landscape per product, then **sequenced** the launches so the stories
  built on each other rather than cannibalising one another.
- Coached and prepared **named spokespeople** for each product, with a shared FAQ so no
  one contradicted anyone else.
- Coordinated **earned, owned, and paid** so the press story, the social story, and the
  ads were telling the same thing in the same week.
- Set up a simple **measurement frame** — coverage volume, share of voice, and message
  pull-through — so we could course-correct between launches.

## The outcome

- **50% more media coverage** across the three launches than the equivalent releases the
  year before.
- Journalists treated the launches as one unfolding story, which earned follow-up
  coverage we could never have bought.
- Internally, the product teams stopped competing for the spotlight and started briefing
  from the same page.

### What I'd do differently

I'd bring measurement in even earlier. We had leading indicators by the second launch,
but the first would have been sharper if the baseline had been agreed before the brief,
not after it.
